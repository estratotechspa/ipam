API del IPAM Contrato OpenAPI 3.1 · prueba cada llamada con «Try it out» ← Volver al IPAM

Cómo probar: con la sesión abierta en el IPAM, las llamadas de lectura funcionan directo. Para probar como lo hará un agente, crea un token (pestaña Tokens, rol agente), pulsa Authorize y pega el token en bearerToken. Las escrituras (reservar, registrar IPs…) modifican datos reales: usa rangos y nombres de prueba.
